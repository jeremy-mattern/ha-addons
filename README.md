# Home Assistant Apps

[![Add repository](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fjeremy-mattern%2Fha-addons)

| App | Description |
|---|---|
| [iOS Location Bridge](ios_location/) | Set the GPS location of a USB-connected iPhone from Home Assistant — mirror another tracker or pin a fixed spot. |

## Install

Settings → Apps → App Store → ⋮ → Repositories → add `https://github.com/jeremy-mattern/ha-addons`.
